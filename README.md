# RetailPulse 📊
## Retail Intelligence Dashboard

RetailPulse is a retail analytics project developed using Python, Streamlit, Pandas, and Plotly. It helps analyze customer behavior, predict churn, forecast sales demand, and optimize inventory.

## 🎯 Project Objectives
- Analyze customer purchasing behavior.
- Segment customers using RFM analysis and K-Means clustering.
- Analyze customer churn.
- Forecast sales demand for the next 30 days.
- Identify inventory stockout and overstock risks.
- Generate inventory reorder recommendations.

## 🚀 Features
### 1. Customer Analytics
Analyze customer purchasing patterns and customer segments.

### 2. Churn Analysis
Explore customer churn data to understand customer retention risks.

### 3. Demand Forecasting
Visualize sales trends and 30-day demand forecasts.

### 4. Inventory Optimization
Analyze inventory levels, identify potential stockouts and overstock situations, and support reorder planning.

### 5. Interactive Dashboard
Explore retail insights using interactive charts, metrics, and visualizations.

## 🛠️ Technologies Used
